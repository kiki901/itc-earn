# ITC Earn

ITC Virtual Currency App — Earn, Stake, Farm, Trade!

## Features
- Daily Login Rewards (1-7 ITC/week)
- Animal Marketplace & Farming
- Lucky Wheel & Gift Box
- Staking (60-day lock plans)
- Buy/Sell ITC (manual, admin-approved)
- 3 Languages (Arabic, English, French)

## Install
1. Go to [Releases](../../releases)
2. Download the latest APK
3. Enable "Install from unknown sources"
4. Install and enjoy!
